# derive

Owns `Blueprint.derive`, `newest`, `all`, `problems` and `problem` (GOAL17-derived-reads): a read worked out from the
records it looks at and stored nowhere, and what can fail beside a thing. `Blueprint.read` takes a derive in `derive:`.
The compiler refuses a look whose `by` is not the root's id, a look at an actor thing, an `adds` name that is a stored
field, and a `max` outside 1 to 100. Test: `derive.test.ts`.
