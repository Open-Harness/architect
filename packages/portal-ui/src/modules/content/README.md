# content

The components the portal shows and edits content with, each HeroUI Pro's own under our name (F7): `Card` and `CardGroup`
(`ItemCard`, `ItemCardGroup`), `Peek` (`HoverCard`), `Command`, `Code` (`CodeBlock`), `Markdown` and `Editor` (`RichTextEditor`).
`service.ts` is the only file that names Pro.

Tests: `content.test.ts` reads the source (Pro is not needed to run it); the declared names and the exported ones must agree.
