# live

What the environment did in the window, read from the snapshot's `telemetry`: the environment and window the top bar names, the tally the rail
shows (calls, answered, refused, defects) for some operations or all, the newest calls, and why a source has nothing to say. Pure. With no
live source every number is `not yet`; a source that failed gives its reason and no number, never a zero (`design/portal.md`, "the holes").
The rail lists two calls (`RAIL_CALLS`) because check 21 K counts them. Test: `live.test.ts`.
