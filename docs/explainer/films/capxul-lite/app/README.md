# Capxul Lite, as a design

A stripped-back Capxul, written as if all of Orthograph existed: one contract that is a company's treasury, with
budgets built into it, and a server that keeps each payment's reason and the books.

**Nothing here is compiled or run.** It is the text the film and its supplement quote. Most of its syntax is real or
decided (`examples/budgets`, K20, K23, K25, M6-chain, M6-money). A line that ends `// new` is a proposal made by this
design, and is drawn with an amber edge wherever it is shown. `falls-out/` holds sketches of what would be generated.
