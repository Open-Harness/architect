# Essays

Long-form writing about what Orthograph is and why. The reference docs (`docs/canon/`) say how each part works; these
pieces make the case and answer the objections. Each one stands alone.

| Piece | What it is for |
|---|---|
| [The plan that compiles](the-plan-that-compiles.md) | the case: why prose plans fail agents, Orthograph's move, and what changes |
| [How Orthograph fits together](how-it-fits-together.md) | the parts and how they meet, with Plugged In worked from one sentence to green |
| [The hard questions](the-hard-questions.md) | the strongest objections, answered, with what is built and what is only decided |
| [Orthograph, in short](short-forms.md) | a one-line, a one-paragraph and a thirty-second spoken description |

Every claim is checked against the code on `goal/stage-1`. A part is marked **runs today**, **being built**,
**decided for 1.0** or **open**, the same marks the reference docs use. Each piece ends with its sources.
