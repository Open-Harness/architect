# Builders' fixtures

Packages a builder made to prove its own slice with unit tests and evidence, not checks. `e2e/fixtures/` belongs to the
✍️ authors and a builder never edits it (AGENTS.md); a builder's fixture lives here instead.

- `vault/`: `@fixture/vault`, a feature with its own store `ledger` (M1.17). Its `two-stores` variant writes two stores.
