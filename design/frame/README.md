# The frame, retired: where each page went

The frame was the design written on 17 and 18 November 2026, before the canon. It is retired by
[K41](../decisions/K41-canon-map.md) (Aaron, 23 November 2026: "yes to the canon map"). The canon,
[`docs/canon/`](../../docs/canon/README.md), now says what the frame said, one concept per page.

Each page is kept, word for word, as a dated record in
[`history/retired-2026-11-23/frame/`](../history/retired-2026-11-23/frame/README.md). Read it for the reasoning behind a
call; read the canon page for what holds today. A canon page marked "planned" below isn't written yet
([`outline.md`](../../docs/canon/outline.md) says which layer writes it), and until it is, the record is the fullest
account.

[`questions.md`](questions.md) stays here: the questions K2 answered, kept as the reasoning behind each call.
