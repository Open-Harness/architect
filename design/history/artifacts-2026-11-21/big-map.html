05 What you can run and audit today

Run it

  • The beta's proof: on goal/stage-1, pnpm nx run e2e:stage1 runs Plugged In's 7 journeys locally.
  • The Safe with hats spike: on goal/safe-hats, spikes/safe-hats-module/run-all.sh runs the Safe and Hats proofs, the budgets module, the fuzz and the Anvil run.
  • The on-chain done check: on goal/on-chain, pnpm nx run e2e:on-chain. It is red by design until the slices land.
  • Climb a journey yourself: in examples/plugged-in, run ortho prove --env local.

Audit it

  • What's built against what's claimed: design/scope.md, read from the code, not from the milestone ticks.
  • Every call and why: design/decisions/. Start with K28 (releases), K24 (UI SDK), K29 (UI layer) and K31 (app map).
  • Each goal's own account: the "Where it stands" section in its goal file, and its snag log (03-snags.md, 04-snags.md).
  • The reviews: every merged pull request carries a 🔍 verdict comment. Codex's findings are answered in their threads.

K29 and K31, both in review. You declare meaning and the map, never the look. Everything between the blueprint and UI SDK's widgets is generated.

Mount the projection once

// blueprint/projections/web.ts
import { Blueprint } from "orthograph";
import { web } from "@orthograph/projections";

export default Blueprint.use(web, { frameworks: ["react"] });

The app and its navigation

// blueprint/app/app.ts
export default Blueprint.app({
  description: "Claim a name and keep a public page of links.",
  layout: Blueprint.layout.sidebar,
  home,
  nav: [
    Blueprint.nav.group({ title: "Your page", pages: [profile, edit] }),
    Blueprint.nav.group({ title: "Settings", pages: [account], folded: true }),
  ],
});

One page: the what, never the look

// blueprint/app/pages/profile.ts
export default Blueprint.page({
  description: "A claimed name's public page and its links.",
  route: { path: "/@:handle", params: { handle: Handle.fields.name } },
  parent: home,
  allowed: [Blueprint.anyone],
  shows: [get],
  offers: [add, order, release],
});

The palette, the breadcrumbs and the agent's map are worked out from these declarations. A blueprint with no app/ folder generates exactly what it generates today, and a check proves it.
